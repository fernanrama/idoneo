Objetivo: preparar y ejecutar todo el hackathon con decisiones claras, una solución demostrable y evidencia para el jurado.

Repositorio privado: https://github.com/fernanrama/hack-finance-uc3m-2026 . Flujo híbrido: consultar coordinacion/CLOUD_Y_LOCAL.md. Los roles son reutilizables; no es necesario mantener seis chats activos ni duplicar tareas entre local y cloud.

## Retomar en la siguiente sesión
1. Leer CONTEXTO.md para conocer hechos, decisiones y pendientes.
2. Consultar coordinacion/CHATS.md para localizar el área adecuada y coordinacion/FLUJO.md para delegar.
3. Incorporar el enunciado original y las claves iniciales en estrategia/RETO_E_IDEAS.md, conservando fuente y diferenciando requisitos de interpretaciones. Las claves de acceso se configuran de forma privada, nunca se copian a estos documentos.
4. Dirección encarga a estrategia el resumen y a producto/evaluación/comunicación su contraste; operaciones convierte la decisión en tareas. Hacer solo preguntas que bloqueen el siguiente paso real.

## Regla práctica
Se puede hablar con cualquier chat. Los cambios que afecten al conjunto se reflejan en archivos y se comunican a dirección para evitar decisiones contradictorias. No es necesario repetir todo el contexto ni mantener manualmente seis conversaciones.
