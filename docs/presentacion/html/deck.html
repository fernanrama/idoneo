Por dentro

Por dentro: todo idóneo en una imagen

✦ Claude un modelo interpreta lenguaje ⚙ código reglas fijas, mismo resultado siempre ● persona decide una persona
Esto es idóneo entero. (1) El cliente habla con la voz de ElevenLabs o escribe en la web en Next.js. (2) Todo llega al backend en FastAPI: el entrevistador, el extractor, las guardas, los cálculos, el verificador y el LLMOps. (3) Cada cambio se guarda como una versión en Postgres, en Supabase. (4) Un asesor valida, y solo entonces el agente de la entidad lee el perfil por nuestro MCP y busca productos en el MCP de MyInvestor. (5) Y aquí está Claude: en el entrevistador, el extractor, el verificador, el juez y el agente de la entidad. Nunca en los cálculos ni en la decisión final.

Un modelo como Claude es muy listo, pero responde con algo de azar. El harness es todo lo que lo rodea para que se comporte igual cada vez. Tiene tres reglas que no se salta. Una: solo pregunta, nunca recomienda. Dos: si el cliente no lo dijo, el dato no entra; cada dato lleva su frase. Tres: el perfil no sale hasta que una persona lo revisa.

LLMOps

LLMOps: si un cambio lo empeora, no sale

Un agente que hoy funciona puede empeorar mañana por un cambio de prompt o de modelo. Lo vemos antes que el cliente.

📏
Trazascada llamada a Claude: tokens, tiempo y coste, sin texto del cliente/operaciones
🧑‍⚖️
Juez LLMpuntúa claridad, neutralidad y empatía; calibrado con notas humanas100 % de acuerdo ±1
🚦
Umbrales0 recomendaciones, 0 datos inventados, nota ≥ 4…umbrales.json
🔧
CI de evalsal cambiar un prompt se repiten las pruebas; si baja, fallaGitHub Actions
Y encima, LLMOps. Cada llamada a Claude deja una traza: tokens, tiempo y coste, sin guardar nada de lo que dice el cliente, y se ve en el panel de operaciones. Un juez, que es otra IA, puntúa cada conversación; antes lo calibramos con nuestras notas y coincide al cien por cien. Hay umbrales escritos: cero recomendaciones, cero datos inventados. Y cuando cambiamos un prompt, la integración continua repite las pruebas con Claude real y, si algo baja, no se publica.
